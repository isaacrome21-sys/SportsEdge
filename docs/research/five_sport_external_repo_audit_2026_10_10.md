### Speed, reliability and Odds API discipline

- **Cache by volatility** (SDV's `sportsdataverse/cache.py`): immutable completed game/PBP snapshots by release SHA; week/season stats hours; pregame injuries minutes; live lines zero or very short TTL. Keys include normalized URL+params+source version. Revision means **new artifact**; stale never masquerades as PIT observation.
- **Bounded parallel free pulls:** independent NFL/CFB/MLB/NBA/NHL stats fetches can run in parallel, subject to provider rate limits. Coalesce duplicate calls and cache team/schedule endpoints. Do **not** parallelize requests sharing the serialized paid Odds API key budget.
- **Preserve Odds API credits:** current NFL 3-market request is already 3 credits with <=10 books and a minimum confirmation reserve; check daily quota before run, deduplicate event/market requests, prioritize scheduled cards, and skip unsupported sports/props. No invented credits or key rotation to bypass quota.
- **Atomic card publication:** separate fetch/validate/render/post stages; write raw receipt and card temp artifacts, then atomically publish only complete version. On partial source failure emit explicit `SKIPPED_SOURCE` / `PENDING_CLOSE` / `NOT_VALIDATED` counts rather than a misleading empty or stale "0 bets."
- **Strict sportsbook quote validity:** market type, exact event and two opposite teams/sides, identical total points or opposite spread handicaps, finite legal American prices, source and capture timestamps. A malformed peer quote must not create fair value. This branch adds the first NFL parser assertions and tests; freshness/last-update expiry across sports remains future work.
- **Backoff/circuit breaking:** bounded retries with jitter for 429/502/503; stop on 401/403/config errors; surface retry-after and data age; preserve manual DK intake on API outage. Always distinguish a real no-edge slate from missing data.
- **Bounded exports:** statcast-mcp's `limits.py` caps requested output rows. Paginate historical pulls and stream compact summaries rather than downloading full pitch logs during a phone-run window.
- **No dependency creep:** source packages are reference implementations, not automatic production dependencies. Pin and scan licenses (esp. NOASSERTION/absent) before any actual code reuse.
