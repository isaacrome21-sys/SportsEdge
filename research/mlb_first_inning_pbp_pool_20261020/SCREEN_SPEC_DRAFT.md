# First-inning PBP pitcher-K / batters-to-plate (M21) — source-screen draft

**UNFROZEN, UNRUN, research-only.**

A first-inning PBP source pack must attest *every completed plate appearance* in BOTH top and bottom first-inning halves (including late substitutions, officially overturned strikeouts, and batters continuing after errors). It has an exact gamePk, home/away team IDs, MLB inning=1, separate starting-pitcher identities for each half, finalized completed-game status, first-pitch/completion/observed-at UTC, count of expected first-inning plate appearances from an independent raw snapshot, and source raw SHA-256. A normalized PA record must have a source event ID, monotonically ordered PA sequence, batter ID, pitcher ID, inning half, and officially credited strikeout boolean. Reject duplicates, omitted innings, wrong half, post-kickoff records, reused games, missing starters, conflicting event attribution or incomplete packet. Only explicitly selected target pitcher starts count toward a pitcher K series; only first-inning half where selected team bats counts toward team BTP series. A player absent from a game never silently gets a zero.

Historical screen: 2025 regular season, all candidate fixtures with immutable strictly-prior observed PBP results and exact subject/team binding.
