# Clarification memo — "40 distinct games per market" (dated 2026-10-22)

Covers: Part 2 §4.1 (`PREREG_NFL_PROPS_PART2_FORWARD_V1.md`), 2B §4
(`PREREG_NFL_PROPS_PART2B_FORWARD_V1.md`), NBA props V1
(`PREREG_NBA_PROPS_FORWARD_V1.md`). Owner ruling #2, 2026-10-22. The frozen
documents are not edited; this memo interprets existing text and applies to
the running clocks. Status: draft pending owner filing.

1. "40 distinct games per market" is a minimum review gate. Each gate is
   phrased "no verdict review before …"; it controls when review may happen.
2. Rows beyond the 40th game are included. No document defines a cap,
   first-40 window, or truncation rule; Part 2 defines the 40 as games
   "contributing graded rows", and game 41 contributes the same way.
3. "Exactly" denotes threshold precision per 2B §4's own definition ("every
   threshold in this document is an exact number, no approximations"):
   39 games is not 40; no rounding. 2B states that definition itself.
   Applying it to Part 2 §4.1 and NBA props V1 is an inference: those
   documents do not define "exactly", and 2B says its rule is carried forward
   from Part 2.
4. Single look: the verdict review happens once, at the first slate close at
   which all gates are met. The rows graded at that point are the sample of
   record. No review is rerun at a later count unless a new version
   preregisters it.
